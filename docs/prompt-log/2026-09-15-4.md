> Ja. Wat je op de screenshot ziet kun je in Astro het beste maken door je projecten in één lijst/data-bestand te zetten en daarna met een .map() automatisch voor elk project een kaart te maken.

Het belangrijkste idee is:

projecten
   ↓
[ project 1, project 2, project 3, ... ]
   ↓
.map()
   ↓
┌──────────────┐
│     FOTO     │
│              │
└──────────────┘
Naam
Omschrijving
Datum

Dus je hoeft niet voor ieder project opnieuw dezelfde HTML te schrijven.

1. Maak eerst een lijst met projecten

Bijvoorbeeld een bestand:

src/
├── data/
│   └── projects.js
└── pages/
    └── portfolio.astro

In projects.js maak je een array:

export const projects = [
  {
    name: "Tagneo",
    description: "Web Development",
    image: "...",
    date: "2026-09-10",
  },
  {
    name: "OonkoO Platform",
    description: "Web Development",
    image: "...",
    date: "2026-08-20",
  },
];

Denk hierbij aan één project als een soort doos:

project
├── name
├── description
├── image
└── date

Je kunt later bijvoorbeeld ook toevoegen:

category: "Web Development"

of:

github: "..."
url: "..."
2. Waarom een array?

Zonder array zou je ongeveer dit moeten doen:

<div class="project">
  ...
</div>

<div class="project">
  ...
</div>

<div class="project">
  ...
</div>

Dat wordt snel vervelend.

Met een array zeg je eigenlijk:

"Hier zijn al mijn projecten. Astro, maak voor ieder project dezelfde kaart."

Dat doe je met .map().

3. In Astro gebruik je .map()

Bovenaan je .astro bestand importeer je de data:

---
import { projects } from "../data/projects.js";
---

Daarna kun je in je HTML iets in deze richting doen:

<div class="projects">
  {projects.map((project) => (
    <article class="project">
      
      <img src={project.image} alt={project.name} />

      <h3>{project.name}</h3>

      <p>{project.description}</p>

      <time>{project.date}</time>

    </article>
  ))}
</div>

Dit is het belangrijkste stukje om te begrijpen.

projects.map((project) => ...)

betekent eigenlijk:

Pak elk project uit projects en noem het tijdelijk project.

Dus bij het eerste project:

project.name

is:

Tagneo

Bij het tweede:

project.name

wordt:

OonkoO Platform

Enzovoort.

4. De foto

Voor je foto's kun je bijvoorbeeld een map maken:

src/
├── assets/
│   └── projects/
│       ├── tagneo.png
│       ├── oonkoo.png
│       └── sopee.png

Daarna kun je de afbeeldingen importeren.

Bijvoorbeeld bovenaan:

---
import tagneo from "../assets/projects/tagneo.png";
import oonkoo from "../assets/projects/oonkoo.png";
---

En vervolgens in je data:

{
  name: "Tagneo",
  description: "Web Development",
  image: tagneo,
  date: "2026-09-10"
}

Let op: als je afbeeldingen vanuit src/assets gebruikt, is het vaak beter om ze via Astro's image-systeem/imports te behandelen dan zomaar een bestandspad als string te gebruiken.

5. De kaarten naast elkaar krijgen

De .map() zorgt alleen voor de projecten.

CSS zorgt ervoor dat ze naast elkaar komen.

Bijvoorbeeld:

.projects {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Dit betekent:

┌───────┐ ┌───────┐ ┌───────┐
│       │ │       │ │       │
│   1   │ │   2   │ │   3   │
└───────┘ └───────┘ └───────┘

┌───────┐ ┌───────┐ ┌───────┐
│   4   │ │   5   │ │   6   │
└───────┘ └───────┘ └───────┘

Dat is ongeveer de structuur van je screenshot.

6. Je projectkaart zelf stylen

Je kunt bijvoorbeeld beginnen met:

.project {
  /* achtergrond */
  /* border-radius */
  /* overflow */
}

En voor de foto:

.project img {
  width: 100%;
  aspect-ratio: 16 / 10;
  object-fit: cover;
}
Waarom object-fit: cover?

Stel je hebt:

foto A → 1920 × 1080
foto B → 1000 × 1000
foto C → 800 × 1200

Zonder object-fit kunnen de afbeeldingen verschillende vormen krijgen.

Met:

object-fit: cover;

zorg je ervoor dat ze netjes hetzelfde vak vullen.

7. Datum

Als je met "duplicatie datum" publicatiedatum bedoelt, zou ik het zo opslaan:

date: "2026-09-10"

En in je HTML:

<time datetime={project.date}>
  {project.date}
</time>

Nog beter is later om de datum mooi te formatteren naar bijvoorbeeld:

10 september 2026

Maar ik zou dat pas doen nadat je de basis werkend hebt.

8. Uiteindelijk wordt je structuur dus
src
│
├── assets
│   └── projects
│       ├── tagneo.png
│       ├── oonkoo.png
│       └── sopee.png
│
├── data
│   └── projects.js
│
└── pages
    └── portfolio.astro

En de verantwoordelijkheden zijn:

Bestand	Doet wat?
projects.js	Namen, foto's, omschrijvingen, datums
portfolio.astro	Projecten op de pagina zetten
CSS	Grid, grootte, ruimte, kleuren
assets/projects	Je projectfoto's

Het grote voordeel: als je morgen een nieuw project hebt, hoef je alleen een nieuw object toe te voegen:

{
  name: "Mijn nieuwe project",
  description: "Web Development",
  image: nieuweFoto,
  date: "2026-09-16"
}

De kaart wordt dan automatisch aangemaakt. Je hoeft geen nieuwe <article> te schrijven.

Als je dit zelf wilt bouwen, zou ik als eerste oefening alleen projects.js + .map() maken. Zodra dat werkt, kun je daarna de grid en het design van je screenshot namaken.
