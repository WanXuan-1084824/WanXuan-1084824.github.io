De belangrijkste CSS-techniek hiervoor is Flexbox.

1. Eerst je HTML-structuur

Denk bijvoorbeeld aan deze structuur:

<main class="container">

    <aside class="sidebar">
        <img src="..." alt="Profielfoto">

        <h2>Jouw naam</h2>
        <p>Software-ingenieur</p>

        <!-- contactinformatie -->
    </aside>

    <section class="about">
        <nav>
            <!-- navigatie -->
        </nav>

        <h1>Over Mij</h1>

        <p>...</p>

        <h2>Wat Ik Doe</h2>

        <!-- cards -->
    </section>

</main>

Het belangrijke gedeelte is:

<main class="container">
    <aside class="sidebar">...</aside>
    <section class="about">...</section>
</main>

Je hebt dus een parent (container) met daarin twee children:

.sidebar
.about
2. De twee blokken naast elkaar zetten

Dit is het belangrijkste stukje CSS:

.container {
    display: flex;
    gap: 20px;
}
Wat gebeurt hier?

Normaal gesproken zouden <aside> en <section> onder elkaar komen:

sidebar
about

Met:

display: flex;

worden ze standaard horizontaal geplaatst:

sidebar   about

En:

gap: 20px;

zorgt voor ruimte tussen beide:

sidebar  ←20px→  about
3. De sidebar smaller maken

In jouw afbeelding is de sidebar ongeveer 250px breed en het About-gedeelte veel breder.

Je zou bijvoorbeeld kunnen beginnen met:

.sidebar {
    width: 250px;
}

En voor .about:

.about {
    flex: 1;
}

flex: 1 betekent hier eigenlijk:

"Gebruik de resterende ruimte."

Dus bijvoorbeeld:

┌────────────┐   ┌───────────────────────────────────┐
│  sidebar   │   │              about                │
│   250px    │   │          resterende ruimte        │
└────────────┘   └───────────────────────────────────┘

Dit is een belangrijk concept om te onthouden:

width → hoeveel ruimte wil ik?

flex: 1 → pak de overgebleven ruimte.

4. De achtergrond van de pagina

In jouw screenshot is de hele achtergrond bijna zwart.

Bijvoorbeeld:

body {
    background: #111;
    color: white;
}

Maar let op: body heeft standaard wat ruimte. Daarom zie je vaak:

body {
    margin: 0;
}

Dus je kunt beginnen met:

body {
    margin: 0;
    background: #111;
    color: white;
}
5. De sidebar eruit laten zien als een kaart

Je sidebar heeft afgeronde hoeken en een donkergrijze achtergrond.

Bijvoorbeeld:

.sidebar {
    background: #1e1e1e;
    border: 1px solid #333;
    border-radius: 20px;
    padding: 30px;
}

Hier zijn vooral deze drie belangrijk:

background
background: #1e1e1e;

maakt de kaart donkergrijs.

border-radius
border-radius: 20px;

maakt de hoeken rond.

Zonder:

┌──────────────┐
│              │
└──────────────┘

Met:

╭──────────────╮
│              │
╰──────────────╯
padding
padding: 30px;

geeft ruimte binnen de kaart.

6. Padding vs margin

Dit is heel belangrijk als je CSS leert.

Stel:

.sidebar {
    padding: 30px;
}

Dan krijg je:

┌─────────────────────┐
│   ← 30px            │
│     Naam             │
│                     │
└─────────────────────┘

Padding = ruimte binnen een element.

Margin is ruimte buiten een element.

.sidebar {
    margin-right: 20px;
}

Maar omdat we gap gebruiken op .container, hebben we die margin-right niet nodig.

7. De profielfoto rond maken

In jouw screenshot is de profielfoto rond.

Je kunt beginnen met:

.sidebar img {
    width: 130px;
    height: 130px;
    border-radius: 50%;
}

50% bij border-radius maakt een vierkante afbeelding rond.

Dus:

width: 130px
height: 130px

maakt:

┌──────────┐
│          │
│   foto   │
│          │
└──────────┘

en:

border-radius: 50%;

maakt:

    ◯
8. De profielfoto in het midden zetten

Als je de foto in de sidebar wilt centreren, kun je de sidebar bijvoorbeeld gebruiken als flex-container:

.sidebar {
    display: flex;
    flex-direction: column;
    align-items: center;
}

Hier gebeuren twee dingen.

flex-direction

Normaal:

display: flex;

gaat horizontaal:

A B C

Met:

flex-direction: column;

wordt het:

A
B
C

Dat is precies wat je in de sidebar wilt.

align-items
align-items: center;

centreert de onderdelen horizontaal:

       foto
        ↓
      ◯
      
     Naam

Je sidebar bestaat eigenlijk uit meerdere onderdelen:

Ervaring

Je kunt daarom bijvoorbeeld een apart element maken:

<div class="contact-item">
    <span>E-MAIL</span>
    <p>email@example.com</p>
</div>

En CSS gebruiken voor de afstand:

.contact-item {
    margin-top: 20px;
}

Je hoeft dus niet alles met position: absolute te plaatsen.

Mijn advies als beginner: probeer eerst Flexbox + margin + padding.

Dat is veel makkelijker te onderhouden.

10. Het About-gedeelte

Het rechter gedeelte kun je ook als kaart maken:

.about {
    flex: 1;
    background: #1e1e1e;
    border-radius: 20px;
    padding: 30px;
}

Daarna kun je de navigatie bovenaan zetten.

Bijvoorbeeld:

<section class="about">

    <nav class="navigation">
        <a>Over</a>
        <a>CV</a>
        <a>Portefeuille</a>
        <a>Contact</a>
    </nav>

    <h1>Over Mij</h1>

    ...
</section>

En dan:

.navigation {
    display: flex;
    gap: 30px;
}

Daardoor worden je menu-items:

Over    CV    Portefeuille    Contact

in plaats van:

Over
CV
Portefeuille
Contact
11. De kaarten onder "Wat Ik Doe"

Dit is weer hetzelfde idee.

Je hebt bijvoorbeeld:

<div class="cards">

    <div class="card">
        <h3>UI/UX-Ontwerp</h3>
        <p>...</p>
    </div>

    <div class="card">
        <h3>Frontendontwikkeling</h3>
        <p>...</p>
    </div>

</div>

Dan kun je:

.cards {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 20px;
}

grid is hier handig omdat je 2 kolommen wilt:

┌───────────────┐  ┌───────────────┐
│ UI/UX         │  │ Frontend      │
└───────────────┘  └───────────────┘

┌───────────────┐  ┌───────────────┐
│ Backend       │  │ Machine       │
└───────────────┘  │ Learning      │
                   └───────────────┘
De belangrijkste CSS die je nu moet begrijpen

Voor jouw pagina zou ik deze volgorde aanhouden:

Stap 1 — Layout
.container {
    display: flex;
    gap: 20px;
}
Stap 2 — Sidebar
.sidebar {
    width: 250px;
}
Stap 3 — Rechter gedeelte
.about {
    flex: 1;
}
Stap 4 — Kaarten
.cards {
    display: grid;
    grid-template-columns: 1fr 1fr;
}

Als je deze vier dingen begrijpt, heb je al een groot deel van de layout uit je screenshot nagebouwd.

Kleine oefening voor jou 👨‍💻

Probeer eerst alleen dit te maken:

.container {
    /* probeer hier de sidebar en about naast elkaar te krijgen */
}

.sidebar {
    /* probeer de sidebar ongeveer 250px breed te maken */
}

.about {
    /* probeer de resterende ruimte te laten innemen */
}

Hint: de drie eigenschappen die je moet zoeken zijn:

display: flex → width → flex: 1
