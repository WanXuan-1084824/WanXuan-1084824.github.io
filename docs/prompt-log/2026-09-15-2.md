> Ja. Wat je op de afbeelding hebt is eigenlijk een lijst met kleine buttons, en in elke button staat:

een logo/icon
de naam van de technologie
een randje
bij :hover → verandert de kleur naar de echte kleur van het logo

Omdat je met Astro werkt, zou ik dit stap voor stap bouwen.

1. Denk eerst aan één tech-item

Bijvoorbeeld React:

<div class="tech-item react">
    <span>⚛</span>
    <span>React.js</span>
</div>

Het belangrijkste hier is:

class="tech-item react"

Waarom twee classes?

.tech-item → algemene styling voor alle tech-items
.react → specifieke kleur voor React

Dus later kun je bijvoorbeeld doen:

.react:hover {
    color: ...;
}
2. Maak eerst het algemene vakje

Je kunt ongeveer hiermee beginnen:

.tech-item {
    display: flex;
    align-items: center;
    gap: 8px;

    border: 1px solid #ddd;
    padding: 6px 10px;
}

Denk even na wat elke regel doet:

display: flex → logo en tekst naast elkaar
align-items: center → netjes verticaal uitlijnen
gap → ruimte tussen logo en tekst
border → het grijze randje
padding → ruimte binnen het vakje
3. Zorg dat alle items naast elkaar komen

Je hebt waarschijnlijk een container nodig:

<div class="tech-stack">
    <!-- alle tech items hier -->
</div>

En dan:

.tech-stack {
    display: flex;
    flex-wrap: wrap;
    gap: 8px;
}

flex-wrap: wrap is hier belangrijk.

Zonder wrap proberen alle technologieën op één lange regel te staan.

Met wrap gebeurt dit:

React.js  Next.js  Expo  Astro  TypeScript
Flutter   Dart     ...
Go        Python   ...

Precies zoals op je screenshot.

4. Hover-kleur

Nu komt het leuke gedeelte.

Voor React zou je bijvoorbeeld kunnen proberen:

.react:hover {
    color: #61dafb;
}

Dus:

normaal:
React.js → donker

muis erop:
React.js → React-blauw

Je kunt hetzelfde principe gebruiken voor andere logo's:

.next:hover {
    color: ...;
}

.astro:hover {
    color: ...;
}

.python:hover {
    color: ...;
}

Tip: probeer eerst alleen React werkend te krijgen. Daarna kopieer je het patroon naar de rest.

5. Maar je hebt nog echte logo's nodig

Op je screenshot zijn het geen emoji's maar echte technologie-iconen.

Daarvoor kun je bijvoorbeeld Simple Icons gebruiken. Dat is handig omdat het logo's van React, Next.js, Astro, Python, Docker enz. bevat.

Bijvoorbeeld conceptueel:

<svg class="icon">
    ...
</svg>

of via een icon library.

Als je wilt dat de logo's zelf ook van kleur veranderen, is dit iets anders dan alleen de tekst kleuren. Dan moet je letten op fill of color, afhankelijk van hoe je het icoon toevoegt.

Mijn advies voor jou

Bouw het in deze volgorde:

Stap 1
Maak alleen:

[ ⚛ React.js ]

Stap 2
Maak het randje en de spacing.

Stap 3
Maak React:hover blauw.

Stap 4
Vervang ⚛ door het echte React-logo.

Stap 5
Maak daarna Next.js, Astro, Python enz.

Zo hoef je niet meteen 20 dingen tegelijk te begrijpen.
