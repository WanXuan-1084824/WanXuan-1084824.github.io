1. Denk eerst aan de structuur

Je wilt de schoolnaam + jaartal in één rij zetten. Bijvoorbeeld:

<div class="opleiding">
    <div class="opleiding-header">
        <h3>Hogeschool Rotterdam</h3>
        <span>2025-heden</span>
    </div>

    <p>AD Software Development</p>
</div>

Het belangrijkste hier is:

<div class="opleiding-header">

Daar zitten de twee dingen die naast elkaar moeten staan in.

2. Geef die header Flexbox

In je CSS:

.opleiding-header {
    display: flex;
    justify-content: space-between;
}

Wat gebeurt hier?

display: flex → zet de elementen naast elkaar.
justify-content: space-between → duwt het eerste element helemaal naar links en het tweede helemaal naar rechts.

Dus:

Hogeschool Rotterdam                         2025-heden
3. Waarom werkt text-align: right alleen niet goed?

Je zou misschien dit proberen:

span {
    text-align: right;
}

Maar dat verplaatst het element zelf niet naar de rechterkant. text-align bepaalt vooral hoe tekst binnen een element wordt uitgelijnd.

Flexbox is hier handiger omdat je eigenlijk zegt:

"Zet deze twee elementen in dezelfde rij en plaats ze aan de twee kanten."

4. Voor jouw andere opleidingen

Je kunt precies hetzelfde principe gebruiken:

Hogeschool Leiden                              Sep. 2024 - Dec. 2024
HBO Informatica: Forensisch ICT

en:

De Passie                                      ...
Middelbare school

Je hoeft dus niet voor ieder jaartal een ingewikkelde CSS-regel te maken. Zorg vooral dat je HTML ongeveer deze structuur heeft:

<div class="opleiding-header">
    <!-- schoolnaam -->
    <!-- jaartal -->
</div>

<!-- opleiding -->

Probeer dit eerst zelf in jouw HTML te zetten. Als je daarna je huidige stukje HTML + CSS van Opleiding hier plakt, kan ik precies aanwijzen waar je div en CSS moet toevoegen, zonder je hele code voor te schrijven.
